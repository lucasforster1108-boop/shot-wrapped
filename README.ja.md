# スクショ年報 ShotWrapped

> 写真は「どこに行ったか」の記録。スクショは違います。忘れたくなくて撮ったもの、証拠に残したもの、値段を比べた跡。今年あなたが本当に気にしていたことは、だいたいスクショの中にあります。

## 作ったきっかけ

きっかけは地味です。「ストレージの空き容量が少なくなっています」という通知でした。

写真を消せば済むと思って開いたら、写真は大したことなくて、スクショが3,000枚以上ありました。認証コード、宅配の受取コード、途中で終わったチャットの画面、買う前に比べた値段のスクショ……。撮ったときは「これは残しとかなきゃ」と思ったやつばかりで、その後一度も開いていない。

かといって、領収書とか保証書が混ざってたら怖くて一括削除もできない。一枚ずつ見る気力もない。

で、400枚くらい眺めたところで気づいたんですが、スクショって写真より正直なんですよね。写真はだいたい盛ってます。スクショは盛れない。何月に忙しかったか、深夜に何を考えていたか、お金がどこに消えたか、全部出てくる。だったらスクショだけ読んで「年報」を作る道具があってもいいだろう、ということで作りました。消すかどうかは、年報を見てから決めればいい。

## できること

- スクショを放り込むと、枚数、容量、いちばん撮った月、深夜（23時〜朝5時）に撮った割合を出します
- 重複探し。念のため3回撮った同じ画面とか、知覚ハッシュで見つけて、各グループで一番古い1枚だけ残す想定にします
- 一部だけOCRで文字を読んで、期限切れゴミ（コード類）、支払い・領収書、買い物、チャット、メモ、移動、に仕分け。全体の数はそこからの推定です。推定だということは画面にも書いてあります、盛ってません
- 年報カードを5枚作ります。総数、いちばん忙しかった月、深夜率、なかなか消せないカテゴリ、空けられそうな容量。1080×1440のPNGで、そのまま投稿できます
- 削除候補リスト（ファイル名の一覧）を出します。**この道具自体は1枚も消しません。**消すのはあなたの仕事です。大事な領収書を消した責任は負えないので

## 使い方

1. このリポジトリの `index.html` をダウンロード
2. ダブルクリックでブラウザで開く
3. スマホのスクショをドラッグ（先にPCへコピーするか、フォルダごと選んでください）

手元にスクショがない場合は「サンプルを見る」ボタンがあります。428枚の作り物のスクショで、どんな年報になるか先に確認できます。

## 先に言っておくこと

- OCRはサンプル方式です。既定では60枚だけ読んで割合を出すので、数千枚ある人はカテゴリの数字を「だいたいの目安」として見てください
- ファイルには一切触りません。重複判定は「見た目が似ているか」だけ、リストもただのリストです
- スマホのブラウザでフォルダを選ぶのは正直しんどいので、この版はPCのブラウザ前提です。コピーの手間が一回増えます、すみません
- OCRエンジン（Tesseract.js）は初回だけネットから読み込みます。読み込めなくても統計と重複とカードは出ます。カテゴリ欄が空になるだけです

## プライバシー

計算は全部あなたのブラウザの中です。サーバーなし、アカウントなし、アップロードなし。タブを閉じたら何も残りません。認証コードや注文画面を読む道具なんだから、これは売り文句じゃなくて最低限だと思っています。

## 中身

HTMLファイル1個、素のJavaScript、ビルドなし、バックエンドなし。ハッシュは9×8に縮めたdHash、OCRは必要なときだけ読み込むオプションです。改造したければこの1ファイルをいじってください。壊したら再ダウンロードすれば済みます。
