# 스크린샷 연말결산 ShotWrapped

> 사진은 내가 어디를 다녀왔는지 보여줘요. 스크린샷은 좀 달라요. 잊어버릴까 봐 찍어둔 것, 증거로 남긴 것, 가격 비교한 흔적. 올해 내가 진짜로 신경 쓴 게 뭔지는 대개 스크린샷 안에 다 들어 있어요.

## 만든 이유

계기는 좀 초라해요. "저장 공간이 부족합니다" 알림이 떴거든요.

사진을 지우면 되겠지 하고 앨범을 열었는데, 사진은 별로 없었고 스크린샷이 3천 장이 넘게 쌓여 있었어요. 인증번호, 택배 수령 코드, 하다 만 채팅 화면, 사기 전에 비교해둔 가격표……. 찍을 때는 다들 "이건 남겨둬야 해" 싶었던 것들인데, 그 뒤로 한 번도 다시 열어본 적이 없더라고요.

그렇다고 영수증이나 보증서가 섞여 있을까 봐 한 번에 다 지우지도 못하겠고, 한 장씩 넘겨볼 기력도 없고요.

한 400장쯤 넘겨보다가 깨달은 건데, 스크린샷이 사진보다 훨씬 솔직해요. 사진은 보통 꾸며서 찍잖아요. 스크린샷은 꾸밀 수가 없어요. 어느 달이 제일 바빴는지, 새벽에 뭘 생각하고 있었는지, 돈이 어디로 샜는지 다 드러나요. 그래서 스크린샷만 읽어서 "연말결산"을 뽑아주는 도구를 만들었어요. 지울지 말지는 결산을 보고 나서 정하면 되니까요.

## 할 수 있는 것

- 스크린샷을 끌어다 놓으면 총 장수, 차지하는 용량, 가장 많이 찍은 달, 심야(밤 11시~새벽 5시)에 찍은 비율을 뽑아줘요
- 중복 찾기. 혹시 몰라서 같은 화면을 세 번씩 찍어둔 것 같은 경우를 지각 해시로 찾아내고, 그룹마다 가장 오래된 한 장만 남기는 걸로 계산해요
- 일부만 OCR로 글자를 읽어서 기간 지난 쓰레기(인증번호, 수령 코드), 결제·영수증, 쇼핑, 채팅, 메모, 이동으로 나눠요. 전체 숫자는 거기서 추정한 값이고, 추정치라는 건 화면에도 그대로 써놨어요. 전수 조사한 척 안 해요
- 연말결산 카드 5장을 만들어요. 총 장수, 가장 바빴던 달, 심야 비율, 차마 못 지우는 카테고리, 비울 수 있는 용량. 1080×1440 PNG라서 그대로 올릴 수 있어요
- 삭제 후보 목록(파일명 리스트)을 뽑아줘요. **이 도구가 직접 지우는 건 하나도 없어요.** 지우는 건 직접 하세요. 중요한 영수증까지 날아가면 저도 책임 못 져요

## 사용법

1. 이 저장소에서 `index.html`을 다운로드
2. 더블클릭해서 브라우저로 열기
3. 폰의 스크린샷을 끌어다 놓기 (컴퓨터로 먼저 복사하거나, 폴더째로 골라도 돼요)

당장 스크린샷이 없으면 "샘플 먼저 보기" 버튼이 있어요. 지어낸 스크린샷 428장으로 어떤 결산이 나오는지 미리 볼 수 있어요.

## 미리 말해둘 것

- OCR은 샘플 방식이에요. 기본으로 60장만 읽어서 비율을 내니까, 수천 장 가진 분은 카테고리 숫자를 정확한 장부가 아니라 대략적인 감으로 봐주세요
- 파일은 건드리지 않아요. 중복 판정은 "생긴 게 비슷한지"만 보고, 목록은 그냥 목록이에요
- 폰 브라우저에서 폴더 고르는 건 솔직히 불편해서, 이 버전은 컴퓨터 브라우저 기준이에요. 복사 한 번 거치는 게 귀찮긴 해요, 미안해요
- OCR 엔진(Tesseract.js)은 처음 쓸 때만 인터넷에서 불러와요. 못 불러와도 통계, 중복, 카드는 다 나와요. 카테고리 칸만 비어요

## 개인정보

계산은 전부 본인 브라우저 안에서 끝나요. 서버 없음, 계정 없음, 업로드 없음. 탭을 닫으면 아무것도 안 남아요. 인증번호랑 주문 화면을 읽는 도구인데, 이건 광고 문구가 아니라 최소한이라고 생각해요.

## 속은 이게 다예요

HTML 파일 하나, 순수 JavaScript, 빌드 없음, 백엔드 없음. 해시는 9×8로 줄여서 구한 dHash고, OCR은 필요할 때만 불러오는 옵션이에요. 고치고 싶으면 이 파일 하나만 만지면 돼요. 망가뜨리면 다시 받으면 그만이고요.
