# 截图年报 ShotWrapped

> 相册里的照片，是你去过哪。截图不一样，截图是你怕忘的、想留证的、比过价的——你这一年在意什么，全在里面。

## 为什么做这个

起因挺狼狈的。手机弹了个「存储空间不足」，我去清相册，翻了半天发现照片没多少，截图三千多张。

验证码、取件码、聊了一半的聊天记录、买东西之前比的价……当时截的时候都觉得「这个得留着」，后来一张也没再打开过。删又不敢乱删，怕哪张发票、哪张凭证还在里面。

更逗的是，翻截图的时候我发现，这玩意儿比相册诚实多了。相册里是摆拍，截图里全是真事：几月份最忙、半夜截的都是什么、钱花在哪。所以干脆做了个工具，只看截图，给自己出一份年报。看完再决定删什么，心里有数。

## 它能干什么

- 把截图拖进去，算总数、占了多少空间、哪个月截得最凶、深夜（23 点到凌晨 5 点）截的占几成
- 认重复：连截好几张一样的、截重了的，用感知哈希比出来，每组留最早一张
- 抽样认字：抽一部分截图做 OCR，分出时效垃圾、支付票据、购物比价、聊天记录这几类，再推算全量——是推算，页面上写得明明白白，不冒充逐张数过
- 出五张年报卡：总数、最忙的月份、深夜占比、你最舍不得删的那类、能腾出多少空间，1080×1440 的图，存下来就能发
- 出一份待删清单：重复的、过期的，列成文件名给你。**只出清单，不替你删。**删错了我可赔不起

## 怎么用

1. 下载这个仓库里的 `index.html`
2. 双击，用浏览器打开
3. 把手机截图拖进去（先拷到电脑上，或者选截图文件夹），等它算完

没截图在手边也行，页面上有个「先看示例」，428 张编出来的截图，先看看长什么样再说。

## 说几句实话

- OCR 是抽样的，默认抽 60 张，分类比例是估算。截图特别多的时候，这个数会晃，别拿它当账本。
- 它不动你的文件。去重只认图片长得像不像，清单也得你自己对着删。
- 手机上直接选文件夹不太方便，这版主要是在电脑浏览器里用的。先把截图拷过来吧，多一步，但稳妥。
- OCR 引擎要联网加载一次（用的 Tesseract.js），加载不上也不耽误看年报，只是分类那一栏空着。

## 隐私

所有计算都在你自己的浏览器里跑，没有服务器，没有账号，截图不上传。关掉页面就什么都不剩。这条不是卖点，是这类工具的底线——截图里全是验证码和订单，本来就不该往外传。

## 技术上就这么点东西

一个 HTML 文件，原生 JS，没有构建，没有后端。哈希是把图片缩到 9×8 算的 dHash，OCR 是可选的、按需加载的。想改就直接改这一个文件，改坏了大不了重新下载。
